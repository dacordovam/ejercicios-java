Proyecto Maven - Clínica Dental SonrisaSana
JDK 21. Abrir la carpeta en IntelliJ IDEA, recargar Maven y ejecutar cl.duoc.clinica.Launcher.
También se puede ejecutar con: mvn clean javafx:run

Los archivos ortodoncias.json e implantes.json están en la raíz del proyecto y contienen los cuatro registros de prueba.

IMPORTANTE: Este proyecto se generó a partir del enunciado Forma G y no desde el proyecto Maven base, porque en el mensaje se adjuntó el DOCX de instrucciones y la imagen de referencia, pero no un ZIP del proyecto base. Por eso se incluye una implementación del modelo basada en las reglas y clases del diagrama del enunciado. Si el proyecto base real tiene nombres de métodos o atributos distintos, habrá que adaptar las clases para conservarlo sin reemplazarlo.
